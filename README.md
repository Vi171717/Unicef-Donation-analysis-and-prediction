# Unicef-Donation-analysis-and-prediction
该项目统计了自2014年以来澳大利亚联合国儿童基金会捐赠者的所有捐赠信息，目的是让我们建立预测模型预测捐赠者是否会在首次捐赠六个月内从不定期捐赠转变为定期捐赠，并判断哪些预测者的各项行为特征分析更有可能转变为定期捐赠者。
代码1是一份基础的探索性分析，通过数据可视化分析定期捐赠者相较于普通捐赠者的主要差别。代码结合了定期捐赠者各行各列的数据制作了多种不同的可视化图片用于揭示所有相关的属性、特征、模式和统计数据，并给出可靠的结论。
代码2具有三个部分，第一部分的探索性分析是代码1的进阶，目的是筛选出定期捐赠者最突出的属性和特征用于后续机器学习。第二部分则是开发一个分类模型用于预测首次捐赠者转化为常规捐赠者的可能性，并用F1 score评估模型性能。为了建立更好的模型，我们对业务背景做了进一步的细致裁定和分类，对数据进行更为严谨的清理和整合和分类，同时将筛选具有明显意义的列进行特征工程（feature engineering）。为了让训练的模型拥有更完善且精确的预测准度，我选择了多个模型进行训练对比并引入超参数进一步优化。最后选择最好的预测模型对最近半年的捐赠者数据集进行了一次模型，通过新的一批捐赠者数据和行为特征判断其在未来六个月转化成定期捐赠者的可能性，在对新的数据集放入kaggle验证准确率和排名。
文件1和2文件2分别是对代码1和代码2内容的解读以及分析。同时文件2还通过分析关键行为属性和建立的模型进行高精度收入与成本预估以制定策略帮助联合国儿童基金会对捐赠者进行排序，从而实现更精准的营销定位和个性化服务提高募捐成效。
Test_p2.csv是用于预测捐赠者是否转化成定期捐赠者的数据集，因此没有统计转化情况。Project2Data.csv是自2014年以来的所有捐赠者数据集。
